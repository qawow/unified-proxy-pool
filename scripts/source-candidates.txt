# 每行一条，支持三种写法：
#   https://example.com/http.txt              URL 里能看出协议时自动推断
#   https://example.com/list.txt   socks5     显式指定协议
#   myname=https://example.com/list.txt       显式指定源名

# 不用手工对照现有清单。

# 哪些还活着。空行和 # 开头忽略。
